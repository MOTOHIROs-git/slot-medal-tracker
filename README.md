# スロット持ちメダルトラッカー

スロットのゲーム数・純増・持ちメダルを、ブラウザだけで管理する軽量PWAです。フレームワークやnpmを使わず、データは端末のLocalStorageだけに保存されます。

## 使い方

1. `index.html` をChrome、Edge、Firefox、Safariの最新版で開きます。
2. 純増を選び、ゲーム数を入力して「記録する」を押します。持ちメダルは累積で計算されます。
3. 条件表示では、開始・終了ゲームと目標枚数を最大4件まで設定できます。判定とグラフの帯・目標線が更新されます。
4. グラフはドラッグでパン、ホイールでズームできます。履歴は編集・削除、Undo、CSV入出力に対応しています。

「新規」から機種ごとのセッションを作成できます。各セッションに純増設定、履歴、条件、入力途中のゲーム数が個別に保存されます。

## PWA / オフライン

アプリ自体は `index.html` を直接開いてすぐ使えます。ホーム画面への追加とService Workerのオフラインキャッシュは、ブラウザの仕様上、HTTPS（または `localhost`）で配信した場合に有効になります。初回アクセス後は、全アセットをキャッシュしてオフラインで動作します。

## GitHub Pages 公開

1. このフォルダの内容をGitHubリポジトリのルートへコミット・pushします。
2. GitHubの **Settings → Pages** を開き、`Deploy from a branch` と対象ブランチの `/ (root)` を選択します。
3. 表示されたURLをスマートフォンで開き、ブラウザの「ホーム画面に追加」を選びます。

## 構成

- `app.js`: UI、セッション、履歴処理
- `graph.js`: Canvasベースの折れ線グラフ、ズーム・パン、条件注釈
- `storage.js`: LocalStorage
- `condition.js`: 目標条件の判定
- `csv.js`: UTF-8 BOM付きCSV入出力
- `service-worker.js`: アセットのオフラインキャッシュ
